# Sukses Jaya Teknik

Website statis. Cara pakai di GitHub Pages:
1. Buat repository baru di GitHub, upload semua isi folder ini (index.html dan folder images).
2. Settings > Pages > Source: Deploy from a branch > Branch: main, folder / (root) > Save.
3. Tunggu 1-2 menit, website aktif di https://USERNAME.github.io/NAMA-REPO/
